# Security policy

Outpost is pre-release and does not yet publish supported-version windows or guaranteed response
times. Please report suspected vulnerabilities privately to the repository owner rather than in a
public issue. Include the affected commit/version, impact, safe reproduction steps, and suggested
remediation if known.

Do not send production credentials, radio channel keys, pairing secrets, private messages, member
databases, or precise locations. Rotate anything exposed during investigation.

Deployment hardening and privacy guidance is in [docs/SECURITY.md](docs/SECURITY.md).
